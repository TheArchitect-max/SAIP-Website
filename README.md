# SAIP Website

Public GitHub Pages showcase for the **Secure Actuation Integrity Platform (SAIP)**.

This repository is intentionally separate from the private/proprietary SAIP source repository. It contains only public presentation material: static HTML/CSS and original local SVG artwork.

## Public scope

- high-level product description;
- problem statement and intended relevance;
- high-level capabilities and design principles;
- project status and claim boundaries;
- link back to the TheArchitectMax portfolio HUB.

## Explicitly excluded

This repository does **not** contain proprietary SAIP source code, internal algorithms, private schemas, security-sensitive implementation details, credentials, secrets, databases, authentication, payments, server-side functionality, physical actuator control or private project documentation.

## GitHub Pages

Expected project-site URL after GitHub Pages is enabled from the `main` branch root:

`https://thearchitect-max.github.io/SAIP-Website/`

No GitHub Actions workflow is required for this static site.

## Visual assets

The SAIP integrity-field illustration and favicon in `assets/` are original project artwork created for this public website. No external images, stock media, web fonts, trackers or third-party JavaScript are used.

See `CREDITS.md` for the asset provenance statement.
